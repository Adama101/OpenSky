## Executive snapshot

### What we are building

OpenSky Corp delivers **sovereign, mission-grade situational awareness** for governments and critical-infrastructure operators. We fuse **satellite sensing**, **ground and maritime feeds**, and (in Phase 1) **uncrewed aerial systems (UAS)** into one operations picture: **plan → monitor live → replay and prove**.

### Core promise

> **One mission clock. One map. One evidence trail.**  
> From space to surface to air.

### Why now

- Critical-infrastructure and cyber-physical monitoring markets are growing at **~9–15% CAGR** (industry estimates).
- Commercial satellite tasking and analytics are affordable enough for **national and industrial** programs.
- Morocco combines **mining, ports, EEZ, energy corridors, and border** needs in one strategic geography.

| Heavy defence SI timelines | **Browser-based ops** + modular adapters |

# Part I — Company

## 1. The idea

Mines, ports, borders, and energy sites produce **fragmented data**: satellite imagery, AIS, CCTV, weather, IoT, patrol reports—and later drone video. Each lives in a different console. Leaders lose **minutes to hours** aligning “what space saw,” “what cameras saw,” and “what the field reported.”

**OS Corp** unifies these under **mission objects** (areas of interest, objectives, patrols, incidents)—not anonymous global layers.

**Satellite** → wide-area persistence and change detection.  
**UAS (Phase 1)** → high-resolution custody of targets and corridors.  
**Platform** → single timeline, alerts, and exportable evidence.

**Naming:** “OpenSky” means **expanded visibility for authorized operators**, not public OSINT. Conduct legal review before trademark filing (potential overlap with aviation data brands).

---

## 2. Vision

**Authorized eyes on every critical domain**—nations and infrastructure owners detect threats, environmental risk, and operational failure early enough to act with **confidence and accountability**.

---

## 3. Mission

Build an **integrated intelligence operations platform** that:

1. Fuses **satellite**, **terrestrial**, and **aerial** data into a live **common operating picture (COP)**.
2. Covers the full **mission lifecycle**: brief, execute, monitor, replay, export evidence.
3. Supports **sovereign deployments** (data residency, on-prem option).
4. Scales from **single industrial sites** to **multi-region** maritime and border programs.

---

## 4. Values

| Value | In practice |
| --- | --- |
| **Sovereignty** | Customer owns mission data; no dependence on public demo feeds. |
| **Truth over theater** | Stale or uncertain data is labeled; no fake precision. |
| **Accountability** | RBAC, audit logs, evidence chains for HSE and legal review. |
| **Modularity** | Satellites and UAS integrate via adapters—not globe rewrites. |
| **Operational speed** | Browser COP for command staff; edge gateways for thin links. |
| **Restraint** | Decision support only; rules of engagement stay with the customer. |

# Part II — Market & customers

## 5. Problem & opportunity

**Problems**

1. Fragmented GEOINT and physical security (no shared mission timeline).
2. Coverage gaps between satellite revisit and fixed cameras.
3. Weak post-incident reconstruction for regulators and insurers.
4. OT / perimeter / external movement not fused in one SOC workflow.
5. Monolithic C2 vs point solutions—slow or incomplete.

**Opportunity:** Target the **software fusion layer** (fastest-growing CIP segment per industry analysts)—not airframe manufacturing in Phase 0.

**Differentiation:** Satellite-first **3D COP** · Morocco-first **FR/AR** ops · One mission model into UAS Phase 1.

## 9. Mission lifecycle (E2E user journey)

```
┌──────────────────────────────────────────────────────────────────┐
│                    OS Atlas — Mission lifecycle                   │
├─────────────────┬────────────────────┬───────────────────────────┤
│  PRE-MISSION    │  LIVE OPS          │  POST-MISSION             │
│  Brief & AOI    │  COP + alerts      │  Replay + evidence        │
│  Asset plan     │  Multi-source      │  Coverage analytics       │
│  Approvals      │  Roles + assist    │  HSE / legal export       │
└─────────────────┴────────────────────┴───────────────────────────┘
                          ▲
              Fusion engine + ingest adapters
         (Satellite · Surface · UAS Phase 1)
```

**Operator journey (typical day)**

1. **Brief** — Supervisor defines AOIs and objectives; assigns sensors and shifts.
2. **Live** — Analyst monitors fused tracks; alerts triaged; incidents opened.
3. **Review** — Supervisor replays timeline; exports evidence pack for HSE or authority.

## 11. Data strategy: satellite first, UAS second

### Phase 0 — ingest

| Source | Use | Pattern |
| --- | --- | --- |
| Optical EO | Change, intrusion | Tasking → globe overlay |
| SAR | Cloud/night corridor | Tiles + AOI registration |
| Weather / lightning | Safety | Timeline layers |
| AIS | Port / EEZ | Stream + staleness flags |
| CCTV / VMS | Perimeter | RTSP/ONVIF via gateway |
| IoT / SCADA (read-only) | Gates, levels | Edge MQTT / OPC-UA |

**Satellite ops concept:** Baseline mosaic → change alerts → (Phase 1) tip-to-UAS custody.

### Phase 1 — Vehicle Adapter SDK

| API | Purpose |
| --- | --- |
| `registerAsset()` | Airframe, payload, link type |
| `uploadMission()` | Waypoints / orbits from mission object |
| `telemetryStream()` | Position, mode, link quality |
| `videoStream()` | H.264/H.265 + metadata |
| `detectionStream()` | Onboard AI boxes (optional) |
| `health()` | GCS / SATCOM vs RLOS |

**UAS classes (via partners):** Small VTOL (site) · Tactical FW/VTOL (corridor) · Long-endurance patrol (customer-funded, BLOS).

**Correlation (differentiator):** SAT change → patrol suggestion · AIS gap + cue → reviewed workflow · CCTV + geofence → incident clip · all logged for replay.

# Part V — Governance & risk

## 16. Security & sovereignty

- Zero trust; mTLS inside cluster
- **No anonymous production access**
- Classification-ready segmentation; HSM option
- Export control on dual-use features
- PII minimization and video redaction
- Customer = **UAS operator of record** unless OS Corp certified via partnership
